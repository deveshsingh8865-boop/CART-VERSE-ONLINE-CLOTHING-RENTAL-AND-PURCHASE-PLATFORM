# 🛍️ CartVerse - Online Clothing Rental & Purchase Platform

## 📌 Project Description

CartVerse is an e-commerce platform where users can rent and purchase clothing online.

## 🚀 Features

* Browse clothing products
* Add to cart
* Rent & purchase options
* Responsive design

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* Node.js

## ⚙️ Setup

```bash
git clone https://github.com/deveshsingh8865-boop/CART-VERSE-ONLINE-CLOTHING-RENTAL-AND-PURCHASE-PLATFORM.git
cd CART-VERSE-ONLINE-CLOTHING-RENTAL-AND-PURCHASE-PLATFORM
npm install
npm start
```
